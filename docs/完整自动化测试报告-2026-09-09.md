## 专项验证

### 项目删除

已验证删除项目后：

- 机器记录被删除
- SOP 记录不被删除
- 费用记录不被删除
- 导入历史不被删除
- 原始导入数据不被删除

### 导入完整性

已验证：

- 有管理网、业务网、集群网、计算网或存储网 IP 的行可以导入。
- 不要求每条记录必须有业务网 IP 或集群网 IP。
- 没有任何 IP 的行不会作为失败记录丢弃，会保存到原始导入数据。
- 导入数据按目标项目或工作表项目名称关联。
