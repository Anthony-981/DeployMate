# DeployMate V1.0 更新说明

## 账号与权限

- 新增本地管理员和普通用户账号体系，支持登录、退出、启停用户及角色管理。
- 普通用户的数据按所属账号隔离，管理员可按用户查看和管理数据。
- 强化修改密码校验；密码修改成功后必须使用新密码重新登录。
- 登录窗口补充 DeployMate Logo。

## 首页与数据管理

- 首页升级为数据看板，增加项目状态、近期趋势、最近项目、机器信息和用户数据概览。
- 移除管理员和普通用户首页的“新建项目”快捷入口，项目统一在项目管理页创建。
- 增加分页、搜索和筛选能力，并优化大量数据下的查询与页面加载性能。
- 删除项目时保留历史日报、费用和导入记录，避免业务历史随项目一起丢失。

## 费用与利润

- 费用记录改为一行同时填写考核费用和出差费用，不再选择费用类型。
- 列表直接展示费用合计、考核费用、出差费用和本条利润。
- 费用概览按项目汇总总考核费用、总出差费用和实际利润。
- 兼容旧版费用数据，并同步更新首页统计与 Excel 导出。
- 修复新增费用窗口中“本条计算”内容显示不完整的问题。

## 导入、导出与备份

- 完善 Excel/CSV 导入、字段映射、异常数据修复和多工作表处理。
- 扩充项目、机器、日报和费用导出内容，保留零值、备注及扩展字段。
- 增强 SQLite 与 Excel 备份、恢复和校验流程。

## 质量与兼容性

- 增加用户权限、登录、分页、导入修复、费用利润、性能及回归测试。
- 完善旧数据库自动迁移，新增字段不会影响已有数据。
- Windows 版本继续提供免安装单文件 `DeployMate.exe`。
- 三个平台的安装包均不包含开发数据或预置业务数据；全新安装首次启动创建空的生产数据库。
- V1.0 使用独立版本目录初始化生产数据库，不读取旧版生产数据库；旧数据文件会原样保留。
